# 六套方法提示词

下面是根据用户提供的视频方法重新编写的完整提示词，可单独复制使用。`【主题】`等是运行时需要填写的信息，不是未完成的项目内容。已经提供的信息无需再次填写。

## 1. 学习阶梯：先看地图

```text
我要学习【主题】，当前基础是【基础】，希望最终能完成【具体任务或作品】。
先给我从入门到进阶的学习阶梯，不展开具体授课。
按阶段列出目标相关核心模块，标记必备先修、核心、可选和暂缓。
用 A → B 表示依赖，说明哪些内容缺失会阻断后续学习。
为每阶段给出能观察的验收成果。
区分实现当前目标的最短路线与今后深入学习的路线。
缺少会改变路线的关键信息时集中问一次，其余按明确假设推进。
```

用途：避免碎片化学习，先明确全局、顺序与必要先修。

## 2. 20小时核心筛选：把时间放在目标上

```text
基于学习阶梯，我有【总时间；未指定时20小时】，可用时段是【每日或每周时段】。
按目标贡献、使用频率和先修依赖筛选最重要的核心，不必凑出精确20%的比例。
默认给我10个120分钟单元，每单元末尾安排15分钟复盘。
把诊断、规划、筛资源、学习、练习、自测和复盘全部计入总预算。
每单元列明目标、先修、主资源与核验状态、实操产物、验收标准和时间分配。
如果我的预算不同，就缩小范围或调整单元，不在计划外加时间。
在零基础入门与精通之间划清本次能验证的成果，不能保证20小时精通或固定倍数提速。
只展开当前单元的下一项活动；不要同时替我完成练习。
```

用途：保留必要基础，优先能产生实际成果的知识与练习。

## 3. AI实时考官：检查真实理解

```text
请做我的考官，检查【知识点】是否真正理解并能应用。
依据概念准确、关键步骤完整、独立应用和无关键错误准备评分要点。
每次只问一道题，不先给答案，等我回答后再判断。
按“判断、具体漏洞、必要纠正、连对计数、下一题”反馈。
答错就将连对计数归零，使用提示才答对的不计入独立连对。
换不同题型，连续三道独立通过、且其中至少一道为新情境应用，才算本轮达标。
每个知识点本单元最多三次纠错回合；用完预算、我要求停止或到上限时，记录漏洞与下次任务。
无法核实的答案或未运行的代码请如实标注，不凭“看起来正确”断言已经验证。
现在提出第一题，等我回答。
```

用途：通过主动作答暴露漏洞，不把“读懂答案”当成掌握。

## 4. 一页速查表：压缩已学内容

```text
把我们已学的【内容范围】整理成一页速查表。
用简短层级、关键词或小型对比表，突出概念关系、易混区别、操作步骤和常见错误。
只收纳已学且已纠正的核心，保留影响正确性的条件与边界。
未验证点单独列出；如果没有学习记录，先问我需要整理哪些材料。
控制在约6—10条主要要点，适合截图回顾，末尾附1—3个不含答案的自测问题。
避免把整篇教程缩小字体塞进去；内容太多时优先当前目标，其余标为后续。
```

用途：降低复习成本，让速查表成为检索入口。

## 5. 前置资源过滤：按证据挑资料

```text
我要学习【主题】，当前基础【基础】，目标【目标】，时间预算【预算】。
请优先筛选官方文档、原始资料或讲解准确且有练习的教程。
只推荐本阶段真正需要的少量资源，默认每单元一个主资源，必要时一个备用。
记录名称、作者或机构、可确认链接、相关章节、适用基础与版本、入选理由、核验状态。
能联网时实际检查内容并标明核验日期；不能联网或访问失败时明确未核验。
如果要淘汰某教程，请指出具体错误、版本不适配或不满足目标的内容，给出对照依据。
不能只凭发布时间判断过时，不要虚构链接、更新日期或阅读记录。
我提供了待筛教程时逐项比较；没有材料时给候选入口与待核验标准。
```

用途：减少无效材料，让学习资源与目标、基础、版本相匹配。

## 6. 费曼学习循环：把理解讲出来

```text
针对【知识点】，先用约12岁孩子能理解的语言解释，并给一个生活例子。
必要术语要解释清楚，指出类比的边界，不为简单而改变概念含义。
然后请我用自己的话复述，等我回答；如果我已给出复述，直接检查它。
标出概念混淆、逻辑缺口、边界遗漏和仅重复术语却解释不清的地方。
指出必要修正后，让我再讲一次，不替我把复述全部完成。
复述准确后，用一道新情境问题检查能否应用。
每个知识点本单元最多三次纠错回合；预算耗尽或我要求停止时记录卡点和先修补习任务。
只有相应解释或应用证据存在时，才记录该项达标。
```

用途：通过解释与迁移找出假理解；可以随时嵌入当前学习单元。

## 建议组合

先确定成果目标，搭地图，再筛核心与资源，安排单元；每单元交替练习、自测与必要的费曼复述，结束时更新一页速查和学习检查点。资源过滤发生在使用资料之前，费曼循环发生在理解不稳的位置，不必按六个标题机械排队。
