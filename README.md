# learn-10x：10 倍速学习 Skill

把 Claude 变成你的**私人老师、考官、资源筛选器和学习伙伴**，用「路径 → 筛选 → 测试 → 压缩 → 反馈」的闭环系统，真正学会一项新技能，而不是看完就忘。

## 它解决什么问题

用 AI 学东西（任何东西无论是知识、认知、商业以及所有你想了解和学习的东西），容易，也容易迷糊：几秒钟就能得到解释，但随便提问、随便的答案，一周后什么都没留下。这个 skill 让 Claude 不只是给答案，而是带你一步步学会。

## 六个模块

| 模块 | 作用 |
|---|---|
| 1. 学习阶梯 | 先画出从零基础到精通的完整知识地图，标清依赖关系 |
| 2. 20 小时核心筛选 | 筛出支撑 80% 效果的 20% 内容，拆成 10 个两小时单元 |
| 3. AI 实时考官 | 一题一题提问，直到你连续三轮无错误，消除"看懂了"的错觉 |
| 4. 一页速查表 | 把核心内容压缩成单页，方便反复回顾 |
| 5. 前置资源过滤器 | 学之前先筛掉低质量、过时、误导新手的资料 |
| 6. 费曼学习循环 | 用大白话讲解，再让你复述并找出假理解，循环到讲清为止 |

推荐顺序：**学习阶梯 → 20 小时筛选 → 资源过滤 → （每个单元：费曼循环 + 考官）→ 一页速查表**。

## 安装（Claude Code）

```bash
git clone https://github.com/ArthurCodings/learn-10x ~/.claude/skills/learn-10x
```

安装后，直接对 Claude 说想学什么即可，例如：

- 「我想学 Python 数据分析，帮我画一张学习阶梯」
- 「用 20 小时法帮我规划吉他入门」
- 「考考我刚学的 TCP 三次握手」
- 「用费曼法带我讲透什么是梯度下降」
- 「把我们今天学的内容压成一页速查表」
